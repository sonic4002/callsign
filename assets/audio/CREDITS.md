# Music credits

All tracks were fetched from OpenGameArt.org on 2026-11-24. The licence of each was read on
the track's own page that day. Files are the originals, renamed and not edited.

`manifest.json` also carries each track's measured length, integrated loudness (LUFS) and
peak level, so the player can level them: the tracks differ by more than 30 dB.

## Where credit must appear

CC-BY 4.0 requires the Tri-Tachyon line above to be shown to players (a credits screen is
enough) with the licence named and a note if a track is ever edited. Until the game has a
credits screen, the two menu tracks must not ship in a public build.
